You'll build the commitment yourself, then break it.

Everything runs on a small helper module, `secp256k1.py`. No installs.

```python
from secp256k1 import *

# point_mul(k)        -> k·G
# point_add(A, B)     -> A + B
# hash_to_int(*parts) -> hash of the parts, as a scalar
# ser(P)              -> P as 32 bytes
```

## Task 3: Forge it

Now the attack. Alice wants a second contract that gives the **same** Q.

<PythonPlayground

contract2 = "Alice agrees to pay 0.1 BTC to Bob"

# TODO: pick a new private key d2 so that (d2 + t2)·G == Q
d2 = ...

P2 = point_mul(d2)
Q2 = point_add(P2, point_mul(t2))

assert Q2 == Q
assert P2 != P
print("Same Q, different contract. The commitment is broken.")
`}
/>

If your asserts pass, you just opened one Q to two different contracts.

<ExpandableAlert
    title="Solution code"
    type="solution"
    expandable={true}
    initialLines={0}
>
```python
# Task 1
t = hash_to_int(contract)
Q = point_add(P, point_mul(t))

# Task 2
d_tweaked = (d + t) % N

# Task 3
d2 = (d + t - t2) % N
```

Task 3 is just the algebra from the lesson: you need `d2 + t2 = d + t`, so `d2 = d + t − t2`.
</ExpandableAlert>
